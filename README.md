# Student Study Planner

A simple study planner website for students.

## Features
- Add study tasks
- Set subject, due date, and priority
- Mark tasks as completed
- Delete tasks
- Filter pending and completed tasks
- Save tasks in browser local storage
- Responsive design for smaller screens

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Add your first study task.
